# Опис фронтенду персональної електронної бібліотеки

Документ для захисту курсової. Пояснює **графічний інтерфейс** настільного застосунку: технології, структуру файлів, екрани, читач і зв’язок з бекендом. Максимально просто.

---

## 1. Що таке фронтенд у цьому проєкті

Фронтенд тут — це **не** сайт на React і **не** веб-сторінка в браузері.

Це **настільний GUI** (графічне вікно Windows) на **Python 3 + PySide6 (Qt 6)**.

Простими словами:

- Бекенд = кухня (база, файли, логіка).
- Фронтенд = зал для гостей (кнопки, списки книг, читач, діалоги).

Користувач бачить лише фронтенд. Кожна дія (імпорт, відкрити книгу, зберегти цитату) — це виклик методу бекенду через об’єкт `container`.

Репозиторій:

```
D:\project\electronic-library-frontend
```

Запуск:

```bash
cd D:\project\electronic-library-frontend
python run.py
```

## 2. Технології фронтенду

| Технологія | Навіщо (людською мовою) | Де |
|---|---|---|
| **Python 3** | Мова GUI | увесь проєкт |
| **PySide6** | Бібліотека Qt для вікон, кнопок, списків, діалогів | `gui/ui/*` |
| **QtWidgets** | Головні віджети: `QMainWindow`, `QStackedWidget`, `QPushButton`… | сторінки |
| **QtCharts** | Графіки статистики | `analytics_page.py` |
| **QTextBrowser** | Показ HTML EPUB у читачі (+ CSS) | `reader_page.py` |
| **QPlainTextEdit / QLabel+QPixmap** | Текст PDF і картинка сторінки | `reader_page.py` |
| **QThread** (воркери) | Довгі операції (імпорт, пошук) у фоні, щоб UI не зависав | `gui/ui/workers/base.py` |
| **QSettings** | Локальні налаштування UI (тема, вигляд бібліотеки) | `app_settings.py` |
| **HTML/CSS** | Оформлення тексту EPUB у читачі | CSS у `reader_page` + HTML з бекенду |

Залежності: `requirements.txt` (PySide6 + дзеркальні залежності бекенду для спільного venv).

Важливо: фронтенд **потребує** сусідній каталог `electronic-library-backend` (або `LIBRARY_BACKEND_ROOT`).

## 3. Як фронтенд підключає бекенд

Файл: `gui/bootstrap.py`.

### Крок 1. Знайти бекенд

За замовчуванням:

```
../electronic-library-backend
```

тобто `D:\project\electronic-library-backend`.

Можна перевизначити змінною:

```
LIBRARY_BACKEND_ROOT=D:\path\to\electronic-library-backend
```

### Крок 2. Додати в `sys.path`

Щоб працювало `from app.main import init_backend`.

### Крок 3. Створити контейнер

```python
container = init_backend(data_dir)
```

`data_dir` за замовчуванням: `electronic-library-backend/data`, або `LIBRARY_DATA_DIR`.

Після цього весь GUI тримає один `container` і викликає:

- `container.auth...`
- `container.books...`
- `container.reader...`
- `container.quotes...`
- тощо.

**Немає HTTP.** Це прямий виклик Python-функцій у одному процесі.

## 4. Точка входу застосунку

Файл: `run.py`.

Що відбувається при запуску:

1. Створюється `QApplication` (ядро Qt).
2. Застосовується тема (світла/темна) з `AppSettings`.
3. Викликається `init_app_container()` — піднімається бекенд.
4. Показується `AuthPage` (вхід / реєстрація).
5. Після успішної автентифікації відкривається `MainWindow`.
6. При виході з акаунта — знову екран входу.
7. При закритті програми: безпечно закрити читач + `container.shutdown()`.

Демо-акаунт (після seed у бекенді): `demo` / `demo1234`.

## 6. Головне вікно і «роутинг»

Файл: `gui/ui/main_window.py`.

Це оболонка програми:

- зліва — навігаційна панель (`NavPanel`);
- зверху — заголовок розділу, глобальний пошук, тема, вихід;
- справа/по центру — `QStackedWidget` зі сторінками.

### Як працює навігація (простими словами)

Це **не URL** як у вебі. Це ключі меню:

Приклад ключів з `nav_items.py`:

- `library_all`, `library_reading`, `library_favorites`…
- `collections`, `genres`, `authors`, `tags`
- `quotes`, `notes`, `bookmarks`
- `stats`, `calendar`, `goals`
- `import`, `tools`, `settings`

Метод `MainWindow.navigate(key)` перемикає потрібну сторінку в стеку і задає режим (наприклад, Materials → вкладка «Цитати»).

Читач відкривається окремо: `open_reader(book_id)` / `open_reader_at(...)`.

### Гарячі клавіші (зручно згадати на захисті)

- `Ctrl+O` — імпорт
- `Ctrl+F` — фокус на пошук
- `Ctrl+1` — усі книги
- `Ctrl+,` — налаштування

## 7. Екрани (сторінки) — що бачить користувач і що викликається

### 7.1. Вхід / реєстрація — `auth_page.py`

- Реєстрація нового локального акаунта.
- Вхід існуючого.
- Виклики: `container.auth.register`, `container.auth.login`.
- Після успіху сигнал → відкривається `MainWindow`.

### 7.2. Бібліотека — `library_page.py`

Головний екран книг.

Можливості:

- сітка карток або таблиця-список;
- фільтри за статусом (читаю / прочитані / заплановані…);
- вибране;
- сортування;
- картка/панель деталей книги: метадані, обкладинка, оцінка, статус;
- відкрити читач;
- редагувати метадані (діалог);
- відгук (діалог);
- drag-and-drop файлів для імпорту;
- масове редагування.

Сервіси: `container.search.filter_books`, `container.books.*`, `container.reviews.*`, `container.ocr` (за потреби).

Віджети: `book_card.py` (прогрес-бар на картці), `book_table_model.py`.

### 7.3. Імпорт — `import_page.py`

- Вибір одного чи кількох PDF/EPUB.
- Черга імпорту, прогрес у фоні (`QThread`).
- Drag-and-drop.

Сервіс: `container.imports.import_files`.

### 7.4. Читач — `reader_page.py` (найважливіший функціональний екран)

Вбудований електронний читач **без сторонніх програм**.

#### PDF

1. Бекенд рендерить сторінку: `reader.render_page(...)` → байти зображення.
2. GUI показує як `QPixmap` / `QLabel`.
3. Режим «Текст сторінки»: текст у `QPlainTextEdit` — звідси можна виділити цитату.
4. Навігація: попередня/наступна сторінка, zoom.

#### EPUB

1. Бекенд віддає HTML: `reader.get_content(...)`.
2. GUI показує в `QTextBrowser` з CSS (шрифт, міжряддя, світла/темна/«папір»).
3. Підсвітка цитат через `<mark>`.

#### Під час читання користувач може

| Дія | Як у GUI | Метод бекенду |
|---|---|---|
| Зберегти позицію / прогрес | автозбереження ~кожні 15 с + при виході | `reader.save_position`, `reading.get_progress` |
| Закладка | кнопка в сайдбарі | `bookmarks.create` |
| Цитата | виділити текст → зберегти | `quotes.create` |
| Нотатка | форма в сайдбарі | `notes.create` |
| Зміст (TOC) | панель змісту | `reader.get_toc` |
| Налаштування читача | шрифт, тема, zoom | `reader_prefs.get/set` |
| Перейти до закладки/цитати | клік у списку | `resolve_location` / відкрити локацію |

Також: `books.touch_opened` — оновлює «востаннє відкрито».

### 7.5. Особисті матеріали — `materials_page.py`

Окремий модуль (вимога ТЗ про цитати + зручний огляд усього):

- вкладки: **Цитати**, **Нотатки**, **Закладки**, **Відгуки**;
- пошук по матеріалах;
- показати, з якої книги і з якого місця взято фрагмент;
- перехід у читач на цю позицію;
- видалення.

Сервіси: `quotes`, `notes`, `bookmarks`, `reviews`.

У лівому меню окремо винесені Цитати / Нотатки / Закладки; відгуки доступні тут і з картки книги.

### 7.6. Організація — `org_page.py`

- **Колекції**: створити / редагувати / видалити, додати книги (категорії з ТЗ).
- **Жанри / Автори / Теги**: огляд і перехід у відфільтровану бібліотеку.

Сервіси: `collections`, `tags`, дані книг/метаданих.

### 7.7. Пошук — `search_page.py`

Глобальний пошук з верхньої панелі (мін. ~2 символи, debounce).

- Повнотекст по бібліотеці / вмісту / цитатах / нотатках.
- Сервіс: `container.search.search_fulltext`.

Окремо в бібліотеці є локальний пошук/фільтри/сортування за назвою, автором, жанром, оцінкою, статусом.

### 7.8. Аналітика — `analytics_page.py` (розширення понад мінімум ТЗ)

- статистика читання з графіками (QtCharts);
- календар активності;
- цілі читання (діалог `goal_dialog.py`).

Сервіс: `container.statistics`.

### 7.9. Інструменти — `tools_page.py`

- пошук дублікатів;
- книги з неповною метадатою;
- експорт/імпорт метаданих і «знань» (цитати тощо).

Сервіси: `library_org`, `export`.

### 7.10. Налаштування — `settings_page.py`

- тема інтерфейсу;
- вигляд бібліотеки (сітка/список) і сортування за замовчуванням;
- зміна пароля (`auth`);
- налаштування читача за замовчуванням;
- backup / restore;
- шлях до даних;
- статус OCR.

## 9. Віджети, теми, утиліти

### Віджети (`widgets/`)

- `book_card.py` — обкладинка, назва, прогрес.
- `cover_label.py` — показ обкладинки.
- `empty_state.py` — «пусто» з підказкою.
- `toast.py` — коротке сповіщення про успіх/помилку.

### Теми (`themes/`)

- `tokens.py` — палітра light/dark.
- `theme_manager.py` — застосовує глобальний Qt Style Sheet (QSS).
- Перемикач у топбарі та в налаштуваннях.

### Налаштування UI

`utils/app_settings.py` через `QSettings` зберігає тему, режим бібліотеки тощо **окремо** від SQLite бекенду (це саме налаштування вигляду вікна).

### Воркери

`workers/base.py` — обгортка для запуску довгих задач у потоці, щоб імпорт великої книги не «моровив» інтерфейс.

## 10. Потік даних у GUI (діаграма словами)

```
Користувач клікає «Зберегти цитату»
        ↓
ReaderPage збирає виділений текст + поточну локацію
        ↓
container.quotes.create(...)
        ↓
Бекенд пише в SQLite
        ↓
GUI оновлює список цитат у сайдбарі / materials
```

Аналогічно для імпорту, прогресу, відгуків, колекцій.

## 12. Обмеження фронтенду (чесно на захисті)

1. Підтримуються лише **PDF** і **EPUB**.
2. EPUB рендериться через **`QTextBrowser`**, не через повний браузерний рушій — складний CSS/JS EPUB може виглядати спрощено.
3. Цитати в PDF зручні в режимі текстового шару; для сканів потрібен OCR.
4. Перейменування тегів не реалізовано (лише створити/видалити).
5. Після restore з backup краще перезапустити застосунок.

Це не «дірки в ТЗ», а технічні межі обраного стеку; основний функціонал постановки задачі покритий.

## 14. Що говорити на захисті одним абзацом

> Фронтенд — настільний інтерфейс на PySide6. Точка входу `run.py` ініціалізує бекенд через `gui/bootstrap.py` і показує вікно з навігацією та сторінками. Бібліотека, імпорт, вбудований читач PDF/EPUB, матеріали (цитати, закладки, нотатки, відгуки), колекції, пошук і налаштування реалізовані окремими page-модулями. GUI не містить бізнес-логіки БД: усе йде через `AppContainer` бекенду. EPUB форматується HTML/CSS у `QTextBrowser`, PDF — як зображення сторінки плюс текстовий шар для виділення.
